# Shredded-Shape (`shredded-shape`)

> Dedicated UI/UX Architecture, Forensic DevTools Analyst, Brand & Style Planner, Clean Optical Worker, and WCAG 2.2 OKLCH Actor-Critic Judge.

## Overview

`shredded-shape` decouples frontend engineering, visual physics, and UI/UX quality gates from `franklin-quebragalho` into a self-contained Antigravity plugin and skill suite (`C:\Users\melki\.gemini\config\plugins\shredded-shape\`).

### 4-Stage Actor-Critic Pipeline & Domain Packs

1. **`ui-frontend-analyst` (`agents/ui-analyst.md`):** Forensic inventory of tokens, colors per selector/file, typography, menus, navigation graph, imported icons, spacing defects, component contracts, active stack, Chrome DevTools live probe, 12-Vector AI Slop score, and `Before vs. After` navigation refactoring proposals.
2. **`ui-brand-ux-planner` (`agents/ui-planner.md`):** Scope & brand diagnosis, 5-Plane `OKLCH 60-30-10` palette calibration (zero neon), 7 style archetypes (`Soft`, `Hi-Tech`, `Tactile`, `Elevated`, `Retro`, `Vintage`, `Clinical`) + 6 `SpatialArchetype` slugs, external asset orchestration (`Google Stitch`, `Figma MCP`, `Google Fonts`, `Three.js`/`Unity Hub`), intuitive zero-verbiage UX hierarchy, `<project_root>/DESIGN.md`, and bounded DAG compilation (`<= 5` rules/node, `--json` / `--out`).
3. **`ui-clean-worker` (`agents/ui-worker.md`):** Tactical ReAct execution (`Thought -> Action -> Observation -> Self-Refine`) with 3-layer realistic `box-shadow`, matte frosted glass, polarity-aware dark-mode rim lighting, Mobile-First adaptive postures, `@container` isolated from `subgrid`, `Read-After-Write` SHA-256 verification (fail-closed `--run-tsc`), and executable 5-state FSM.
4. **`ui-quality-judge` (`agents/ui-judge.md`):** Read-only Actor-Critic gatekeeper enforcing polarity-isolated CIE Y / OKLCH WCAG 2.2 contrast ($FNR < 0.001$), `48x48px` coarse touch targets, `:focus-visible`, `DOM == Visual Order`, `prefers-reduced-motion`, anti-XSS, and 12-Vector Anti-AI-Slop checks.
5. **Domain Specialist Packs:**
   - **`clinical-minimalist-ui`:** Clinical EHR/PEP dashboards, deterministic medical calculators, and vector A4 `.sus-grid` print sheets (auto-AAA).
   - **`complex-zero`:** ReAct CDP DevTools + AST anti-fake auditor for `@xyflow/react` infinite canvases, `150ms` WebSocket/Chokidar telemetry, and Next.js 15+ async `params`.
