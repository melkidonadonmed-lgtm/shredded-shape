# Shredded-Shape (`shredded-shape`)

> Dedicated UI/UX Architecture, Forensic DevTools Analyst, Brand & Style Planner, Clean Optical Worker, and WCAG 2.2 OKLCH Actor-Critic Judge.

## Overview

`shredded-shape` decouples frontend engineering, visual physics, and UI/UX quality gates from `franklin-quebragalho` into a self-contained Antigravity plugin and skill suite (`C:\Users\melki\.gemini\config\plugins\shredded-shape\`).

### 4-Stage Actor-Critic Pipeline & Domain Packs

1. **`ui-frontend-analyst` (`agents/ui-analyst.md`):** Forensic inventory of tokens, colors per selector/file, typography, menus, navigation graph, imported icons, spacing defects, component contracts, active stack, Chrome DevTools live probe, AI Slop score, and `Before vs. After` navigation refactoring proposals.
2. **`ui-brand-ux-planner` (`agents/ui-planner.md`):** Scope & brand diagnosis, OKLCH `60-30-10` palette calibration (zero neon), 7 style archetypes (`Soft`, `Hi-Tech`, `Tactile`, `Elevated`, `Retro`, `Vintage`, `Clinical`), external asset orchestration (`Google Stitch`, `Figma MCP`, `Google Fonts`, `Three.js`/`Unity Hub`), intuitive zero-verbiage UX hierarchy, `<project_root>/DESIGN.md`, and bounded DAG compilation (`<= 5` rules/node).
3. **`ui-clean-worker` (`agents/ui-worker.md`):** Tactical ReAct execution (`Thought -> Action -> Observation -> Self-Refine`) with 3-layer realistic `box-shadow`, superior matte frosted glass, polarity-aware dark-mode rim/halo illumination, `Read-After-Write` SHA-256 verification, and executable FSM states.
4. **`ui-quality-judge` (`agents/ui-judge.md`):** Read-only Actor-Critic gatekeeper enforcing CIE Y / OKLCH WCAG 2.2 contrast ($FNR < 0.001$), `48x48px` coarse touch targets, `:focus-visible`, `DOM == Visual Order`, `prefers-reduced-motion`, anti-XSS, and anti-AI-Slop checks.
5. **Domain Specialist Packs:**
   - **`clinical-minimalist-ui`:** Clinical EHR/PEP dashboards, deterministic medical calculators, and vector A4 `.sus-grid` print sheets.
   - **`complex-zero`:** ReAct CDP DevTools + AST anti-fake auditor for `@xyflow/react` infinite canvases, `150ms` WebSocket/Chokidar telemetry, and Next.js 15+ async `params`.
