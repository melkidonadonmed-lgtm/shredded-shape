# Shredded-Shape (`shredded-shape`)

> Dedicated UI/UX Architecture, Forensic DevTools Analyst, Brand & Style Planner, Clean Optical Worker, and WCAG 2.2 OKLCH Actor-Critic Judge.

## Overview

`shredded-shape` decouples frontend engineering, visual physics, and UI/UX quality gates from `franklin-quebragalho` into a self-contained Antigravity plugin and skill suite (`C:\Users\melki\.gemini\config\plugins\shredded-shape\`).

### 4-Stage Actor-Critic Pipeline & Domain Packs

1. **`ui-frontend-analyst` (`agents/ui-analyst.md`):** Headless-safe `[CoT-0]` Intent-First forensic analyst (`pre-plan`, `planner-directed`, `plan-brief`) auditing tokens, polarity, shadows, warning colors, typography, menu character counts, canvas capabilities, AppSec (`AUDIT-SEC-ENV-LEAK`/`AUDIT-SEC-01`), Chrome DevTools live probe, and causal `Friction X -> Impact Y` CLAREZA diagrams.
2. **`ui-brand-ux-planner` (`agents/ui-planner.md`):** Order-dependent ToT planner (`post-analysis` or 1-hop `analysis-directed`), risk-based ambiguity triage, 4 execution routing intents, 5-Plane `OKLCH 60-30-10` + Tailwind v4 `@theme inline` shadows, 7 style + 6 spatial archetypes, external asset orchestration, zero-verbiage UX, Phase 0 Scope Lock, `<project_root>/DESIGN.md`, and bounded DAG (`--mode refactor|greenfield|planner_directed`).
3. **`ui-clean-worker` (`agents/ui-worker.md`):** Tactical ReAct execution (`Thought -> Action -> Observation -> Self-Refine`) with 3-layer realistic `box-shadow`, `@theme inline` elevation, `flow-root`, silent CSS breadcrumbs (`::before`), GPU `.skip-link`, `text-wrap: balance/pretty`, `@container` isolated from `subgrid`, zero secrets/omissions, and `Read-After-Write` SHA-256 verification (fail-closed `--run-tsc`).
4. **`ui-quality-judge` (`agents/ui-judge.md`):** Read-only Double-Pass (`Macro + Micro`) 3-Axis Judge (`ui_code`, `execution_plan`, `technical_audit` via `artifact_axis_judge.py`) enforcing `P0..P3` causal verdicts, polarity-isolated WCAG 2.2 OKLab contrast ($FNR < 0.001$), `48x48px` touch targets, microcopy brevity/intuitiveness, AppSec sinks/secrets, and Anti-AI-Slop checks.
5. **Domain & Bridge Packs:**
   - **`clinical-minimalist-ui`:** Clinical EHR/PEP dashboards, 3-layer clinical nav, deterministic medical calculators, and vector A4 `.sus-grid` print sheets (auto-AAA).
   - **`complex-zero`:** ReAct CDP DevTools + AST anti-fake auditor for `@xyflow/react` infinite canvases, Dagre auto-layout + `setCenter` camera sync, `150ms` WebSocket/Chokidar telemetry (with Windows `/` normalization), hoisted `nodeTypes`, and Next.js 15+ async `params`.
   - **`stitch-canvas`:** Decoupled Google Stitch Canvas bridge (`@google/stitch` CLI `0.13.0` + 18-tool remote MCP `stitch` + `stitch_asset_bridge.py` SSRF-safe `=w{width}` downloader) handing off directly to Stage 1–3 `OKLCH 60-30-10` implementation.
