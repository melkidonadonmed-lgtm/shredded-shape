# Shredded-Shape 9-Axis UI/UX Guardrails (SSOT)

> Keep detailed CSS recipes, token tables, and examples in the `shredded-shape` skills (`ui-frontend-analyst`, `ui-brand-ux-planner`, `ui-clean-worker`, `ui-quality-judge`). Enforce these non-negotiable invariants on every UI edit:

1. **Axis 1 — 4-Stage Actor-Critic Routing:** Follow `ui-analyst` (CoT read-only) -> `ui-planner` (ToT `DESIGN.md` + bounded DAG, `max_discovery_hops: 1`) -> `ui-worker` (ReAct + RAW SHA-256) -> `ui-judge` (Double-Pass 3-Axis WCAG 2.2 judge; fail-closed `UNVERIFIED` on truncated/narrowed scans).
2. **Axis 2 — Perceptual `OKLCH` 60-30-10 & 5-Plane Hierarchy:** Use `oklch()` + `light-dark()` + `color-mix(in oklab, ...)` across 5 planes (`well < canvas < card < card-lit < key`). Never use `#000000` (`L >= 0.118` well, `~0.145` dark canvas, `0.962..0.975` light canvas). Keep focal accents `C <= 0.20` (`> 0.22` hard fail; semantic red `15°..40°` `<= 0.24`). Ban neon/glow/blob tokens, confetti pills, dashed wireframes, gradient text, decorative `>= 3px` side stripes, hyper-rounded cards (`6px–16px`), fake `01/02/03` prefixes, and ALL-CAPS eyebrow spam.
3. **Axis 3 — Polarity-Aware Physical Depth:** In Light Mode use dual `135°` soft or 3-layer shadows (umbra + negative-spread penumbra + zenithal inset catch-light). In Dark Mode separate planes with subtle zenithal top sheen, `1px` top specular rim, deep umbra, and restrained directional lift (`C <= 0.16`, zero glowing borders).
4. **Axis 4 — Mineral Matte Frosted Glass:** Combine translucent `color-mix(in oklab, ...)` (`~74%`), `backdrop-filter: blur(18px) saturate(145%)`, `isolation: isolate`, crisp `1px` top edge, and solid `@media (prefers-reduced-transparency: reduce)` fallback.
5. **Axis 5 — Style & Spatial Lock:** Lock 1 Style Archetype (`soft | hi-tech | tactile | elevated | retro | vintage | clinical`) and 1 Spatial Archetype (`Workbench Split-View | 12-Col Bento | Command Center | Editorial 65ch | Spatial HUD | Vector A4 @media print`) in `DESIGN.md`.
6. **Axis 6 — Relational Spacing & `@container` Layout:** Enforce `border-box`, logical CSS (`inline-size`, `100dvh`, `display: flow-root`), Gestalt proximity (`Inner Gap < Card Padding <= Grid Gap < Section Inset`), concentric radii (`R_in = max(4px, R_out - P)`), Tailwind v4 `@theme inline` shadows, and `@container` cards isolated from `subgrid` (never `@media (min-width)` inside cards).
7. **Axis 7 — Single-DOM Adaptive Navigation:** Support 3 Mobile-First postures (`<600px` Bottom Bar + safe-area, `600–839px` Rail, `>=840px` Collapsible Sidebar), `<= 3` `<nav>` landmarks with unique `aria-label` (never repeat `"navigation"`), `<= 6` items/`<nav>` (`gap >= 8px`, label `>= 13px`), tooltips on collapsed rails, GPU `.skip-link` to `<main id="main-content" tabindex="-1">`, and silent CSS breadcrumbs (`li + li::before` — never raw `/` in HTML).
8. **Axis 8 — Zero-Verbiage Typography, SVGs & WCAG 2.2:** Keep viewport microcopy `<= 60–80` words; ban UI emojis, ASCII/Unicode pseudo-icons (`+`/`×`/`≡`/`▾`/`←`/`→`), and amateur SVGs (use single-library `24x24` Lucide/Material sprites). Enforce `clamp()` (`max <= 2.5 * min`, `60ch..65ch`, `tabular-nums`, `text-rendering: auto` on `body`), `:focus-visible` (`>= 3:1`, interactive only), `DOM == Tab Order`, and `>= 44x44px` fine / `>= 48x48px` coarse targets (`< 40px` blocker).
9. **Axis 9 — GPU Motion, AppSec & 5-State FSM:** Animate only `transform`/`opacity` with `prefers-reduced-motion: reduce`; enforce React 19 native `ref`, Next.js 15+ `await params`, `DOMPurify.sanitize()` (zero raw `.innerHTML` or dynamic code execution), zero client secrets or omission stubs, and real 5-state FSM (`idle | loading | empty | error | success`).
